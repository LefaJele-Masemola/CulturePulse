# 🌍 CulturePulse

**CulturePulse** is an AI-powered web application designed to preserve and promote South African indigenous languages and cultures. By combining augmented reality (AR), voice, and translation technologies, the platform enables users to interactively learn native languages, customs, foods, clothing, and traditions.

## 🧠 Purpose

Many South Africans — especially youth — have become disconnected from their indigenous roots. CulturePulse uses AI for social good by making language and culture education accessible, immersive, and engaging.

## 🚀 Features

- 🌐 **Multilingual Learning** – Choose a language (e.g., isiNdebele, Xitsonga) to explore vocabulary and phrases
- 🔊 **Voice Interaction** – Hear greetings and key terms pronounced in the native language
- 🧠 **Azure Custom Translator** – Real-time translation and custom language support
- 📱 **Augmented Reality (AR)** – Scan real-world items and get cultural translations (e.g., “hat” ➜ “isicoco”)
- 📚 **Cultural Categories** – Explore language, clothing, food, customs, and traditions
- 🤝 **Community-Driven** – Potential for users to contribute terms, voice, or images in future versions

## 🧰 Tech Stack

- **Frontend:** React, HTML5, CSS3, JavaScript
- **Backend:** Python, Azure Functions (Flask/FastAPI)
- **AI / Translation:** Azure Custom Translator, Azure Speech Services, Microsoft Copilot
- **AR Integration:** WebAR / 8thWall or Unity+Vuforia bridge
- **Database:** Azure Cosmos DB
- **Version Control & Collaboration:** GitHub (Branches, PRs, Issues)

## 🔐 Security

- User input validation, sanitization and hashing
- Secure API keys (env variables)
- Role-based access for contributors (future enhancement)

## 💡 Inspiration

Inspired by the need to reconnect with our heritage. Many of us — even team members — don’t fully understand our native languages. CulturePulse bridges that gap using modern tools to revive what matters.

## 🤖 AI for Social Good

CulturePulse uses Microsoft Copilot, Azure AI services, and AR to promote cultural preservation and digital inclusion — making AI accessible for marginalised communities.
